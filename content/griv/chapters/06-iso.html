ISO 感光度

光不夠時的最後手段。用得對是救命,用得多是畫質災難。

ISO 的基本原理

ISO 不是讓感光元件變敏感,而是把收到的訊號放大——雜訊也跟著一起被放大,這套原理跟廠牌無關,完整說明見攝影基礎分頁:光圈・快門・ISO 個別深入。說明書也直接寫了:「使用高感光度拍攝的影像可能出現雜點」p.67。

GR IV 的範圍

ISO 100 ～ ISO 204800,可設為自動或手動 官方規格。

20 萬這個數字是「規格上限」,不是「日常可用範圍」。實務上請把它當成緊急備援。本站建議

怎麼調 ISO

  1. 在拍攝模式下按左鍵(ISO 按鈕)。
  2. 用前電子轉盤或曝光補償改變數值。
  3. 按 Fn 按鈕可以直接跳回 ISO AUTO;再按一次 Fn 回到剛才的固定值。

說明書 p.67

ISO AUTO 的三個設定(整台相機最值得先調的地方)

把 ISO 交給相機自動,但你可以規定它的行為:

MENU → A2 曝光設定 → 感光度設定
項目意思可設範圍初始設定
感光度設定要 AUTO 還是固定值AUTO / 100–204800—
感光度 AUTO 上限自動時最高可以拉到多少下限+1 ～ 最高感光度12800
感光度 AUTO 下限自動時最低到多少最低感光度 ～ 上限−1100
最低快門速度快門慢到這個值時,相機才開始拉 ISO1 秒 ～ 1/1000 秒1/30

說明書 p.26–27、p.67

為什麼「最低快門速度」這麼重要

預設是 1/30 秒。意思是相機會讓快門一路降到 1/30 才開始提高 ISO——但 1/30 拍走動的人一定糊。

本站建議 街拍時把它改成 1/250 秒,上限設 6400。這樣相機會優先保住快門,寧可 ISO 高一點也不讓你拍糊。

這個值有三檔可以選,依你拍什麼調整:
1/125 保守(光線好、主體靜態)/ 1/250 通用(建議從這裡開始)/ 1/500 積極(人多、動作快)。實際使用者的設定從 1/160 到 1/500 都有,見「別人怎麼設」那一章。

高感光度的雜點處理

MENU → A5 影像加工設定 → 去除雜點 → 高感光度 NR
選項意思
自動依感光度自動處理
弱 / 中 / 強固定強度
自定義可以針對每一級 ISO 分別設定強度
關閉不處理

說明書 p.71–72

本站建議:先用「自動」。雜點抑制開太強會讓細節變成塑膠感,這是取捨,不是越強越好。

順帶一提:動態範圍校正

逆光時常常「天空白掉」或「人臉黑掉」。GR IV 可以幫忙拉回來:

MENU → A5 影像加工設定 → 動態範圍校正
項目選項注意
高亮校正自動 / 開啟 / 關閉感光度低於 ISO 200 時不會啟動
陰影校正自動 / 弱 / 中 / 強 / 關閉設為「強」時雜點可能較明顯

說明書 p.95

練習 06
  1. 把「感光度 AUTO 上限」設 6400、「最低快門速度」設 1/250。這是你之後最常用的組合。
  2. 晚上在同一個場景,手動用 ISO 400、3200、25600 各拍一張,放大到 100% 比較顆粒。
  3. 決定一個你自己能接受的 ISO 上限,寫下來。
