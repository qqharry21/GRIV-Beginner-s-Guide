曝光補償・測光・直方圖

相機的測光會被騙。這一章教你怎麼發現、怎麼修。

相機為什麼會把白色拍成灰色

相機測光的預設假設是:「整個畫面平均起來應該是中灰色」。所以——

  • 你拍雪地、白牆:相機以為太亮了 → 拍暗 → 白變灰
  • 你拍夜景、黑衣服:相機以為太暗了 → 拍亮 → 黑變灰、夜景變白天

這不是故障,是測光原理造成的。修正方法就是曝光補償。攝影通識

曝光補償

用曝光補償告訴相機:「你算的太亮了/太暗了,請調整」。

項目規格
靜止影像±5EV,以 1/3 EV 為一階
影片±2EV,以 1/3 EV 為一階

官方規格說明書 p.51

EV 是亮度的單位:+1EV 大約是亮一倍,−1EV 大約是暗一半 攝影通識。

最常用的三個補償
  • 拍白色的東西(雪、白牆、白紙)→ +0.7 ～ +1EV
  • 拍夜景想保留氣氛 → −0.7 ～ −1.3EV
  • 逆光人像,人臉太黑 → +1EV

本站建議 起始值,拍完看直方圖再微調。

在手動曝光模式且感光度設為固定值時,無法進行曝光補償 說明書 p.52。因為那時候三個參數全在你手上,沒有「補償」的對象。

還有一個自動補償

MENU → A2 曝光設定 → 自動曝光補償 → 開啟

開啟後,在光圈優先或快門優先模式下無法獲得正確曝光時,相機會自動調整 說明書 p.52。

測光方式:相機從哪裡讀亮度

MENU → A2 曝光設定 → 測光方式
選項官方說明什麼時候用
多區分割拍攝範圍,綜合判斷預設,九成場合建議
中央重點以中央為重點測光主體在正中間
重點對狹小區域測光主體很小、或只想測某一塊
高亮重點分割測光,突出明亮部份進行曝光夜間霓虹、逆光、舞台建議

說明書 p.65。另外:偵測到臉部或眼部時,「多區」與「重點」會在臉部曝光 p.65–66。

直方圖:照片的亮度成績單

直方圖是一張圖,橫軸從左到右代表「暗 → 亮」,縱軸代表「有多少像素落在那個亮度」。

過曝的亮部救不回來,曝光不足的暗部通常還有救。 所以不確定時,寧可稍暗一點。攝影通識

把直方圖叫出來

MENU → D3 顯示自定義 → 拍攝資訊顯示設定

在裡面可以逐項開關這四個 說明書 p.139:

項目官方說明
直方圖顯示直方圖
格線顯示格線(構圖輔助)
白點警告預計拍攝時會出現白點的部份以紅色閃爍
電子水平儀顯示確認照相機傾斜的指示器

本站建議:新手把這四個全部打開。它們是訓練輪,熟了再關掉。

重播時也能顯示直方圖等資訊,設定在同一頁的「重播資訊顯示設定」p.140。

格線與水平儀的樣式也能改

設定選項位置
格線種類9 網格 / 16 網格D3 顯示自定義
電子水平儀類型水平 + 前後 / 水平D3 顯示自定義
電子水平儀的設計Type1 / Type2 / Type3D3 顯示自定義

說明書 p.34、p.141

拍歪了可以自動修正

MENU → A6 拍攝輔助 → 自動水平補正 → 開啟

相機會補正電子水平儀偵測到的水平傾斜。補正幅度:SR 開啟時最大 1.0 度,SR 關閉時最大 1.5 度 官方規格說明書 p.96。

練習 07
  1. 把直方圖、格線、白點警告、電子水平儀四個全部打開。
  2. 拍一面白牆:先 0EV,再 +1EV。比較兩張的直方圖形狀。
  3. 晚上找一個有霓虹燈的地方,用「多區」和「高亮重點」各拍一張,看亮部有沒有白掉。
