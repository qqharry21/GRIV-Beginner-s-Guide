對焦:讓它清楚

GR IV 有九種對焦方式。你日常只會用到三種,但要知道其他六種在哪。

九種對焦模式

MENU → A1 對焦設定 → 對焦
模式官方說明新手怎麼理解
自動區域 AF
初始設定		在 5×5 的對焦區域進行對焦,對焦於適當的位置相機自己挑。最省事
範圍選擇 AF任意移動 3×3 的對焦區域,自動對焦於區域內適當的位置你圈一塊,相機在裡面挑
選擇 AF指定任意 1 個對焦區域進行對焦你指定一個點。最精準常用
精確 AF在比選擇 AF 小的任意區域對焦對很小的東西
追蹤 AF追蹤主體,持續對焦拍會跑的小孩、寵物
連續 AF半按快門時持續對焦主體前後移動時

說明書 p.58

怎麼指定對焦點

選了「範圍選擇 AF / 選擇 AF / 精確 AF / 追蹤 AF / 連續 AF」之後:

  1. 在拍攝畫面按 OK,進入對焦點可移動的狀態。
  2. 用四向鍵移動對焦點。長按 OK 可讓對焦點回到中央。也可以直接點螢幕。
  3. 按 OK 完成。

說明書 p.61

讓四向鍵直接移動對焦點

如果覺得每次都要先按 OK 很煩:MENU → D2 操作自定義 → 四方位控制器優先動作 → 自動對焦點切換優先設定後,四向鍵就直接移動對焦點,不用先按 OK。長按 OK 可切回快捷鍵功能。說明書 p.61

人臉與眼睛偵測

MENU → A1 對焦設定 → 臉部/眼部偵測 → 開啟 / 僅自動區域 AF / 關閉

設為「自動區域 AF / 範圍選擇 AF / 選擇 AF / 精確 AF」時,相機可以自動偵測人臉、眼睛後對焦 說明書 p.60。

畫面裡有多個人時,可以點選要對焦的那張臉(需要觸摸 AF 有效);在自動區域 AF 下,自動對焦期間按 OK 也能用四向鍵挑臉 p.60。

說明書 p.53

微距:拍很近的東西

按上鍵(微距)進入微距模式,再按一次取消 說明書 p.63。

模式對焦範圍(從鏡頭前端算)
標準約 0.1m ～ ∞
微距模式約 0.06m ～ 0.15m(6 到 15 公分)

官方規格說明書 p.63

微距模式下,如果「對焦」設為快拍或 ∞,相機會改以選擇 AF 動作 說明書 p.63。

手動對焦

  1. 把「對焦」設為 手動對焦。拍攝畫面出現對焦欄。
  2. 按上鍵,對焦欄上出現可調整的標記。
  3. 用曝光補償調整對焦距離;長按 DISP 可放大實時顯示,方便確認。

說明書 p.62

限制對焦搜尋的距離範圍後,對焦會更平滑 說明書 p.60。

以下情況對焦限制器無效

快拍距離優先(Sn)模式、微距模式、對焦設為手動對焦/快拍/∞ 時、以及完全按下快拍時 說明書 p.60。

確認景深的隱藏功能:預覽

把「長按影片按鈕」指定為預覽之後,按住影片按鈕,相機會實際縮到你設定的光圈值,讓你直接看到景深 說明書 p.53。

MENU → D2 操作自定義 → Fn 按鈕設定 → 長按影片按鈕 → 預覽

預覽狀態下無法拍攝或改光圈值,放開就取消 p.53。

練習 08
  1. 切到「選擇 AF」,練習用四向鍵把對焦點移到畫面四個角落各拍一張。
  2. 開啟微距模式,拍 10 張 6～15 公分的近物(食物、葉子、織品紋理)。
  3. 把「對焦輔助」打開,切到手動對焦,體驗輪廓被突顯的樣子。
