    第一次開機

    從拆封到拍下第一張,一步都不跳。

    盒子裡有什麼

    RICOH GR IV 本體、熱靴蓋(已裝在相機上)、二次電池組 DB-120、USB 接線 I-USB198、照相機帶、入門指南 說明書 p.11。

    注意:盒裝沒有記憶卡,也沒有充電器。 充電要另外接支援 USB Power Delivery 的變壓器,或用電腦。專用充電器 BJ-12 要另外買 說明書 p.40。

    步驟一:裝電池與記憶卡

    1. 確認相機已關閉。
    2. 把機身底部的解鎖桿滑向「OPEN」,打開電池／記憶卡蓋。
    3. 注意方向,把記憶卡完全推進去直到「喀嗒」一聲。要取出時,再往內按一下就會彈出。
    4. 按住電池側面的扣爪,把電池推進去。
    5. 蓋上蓋子,把解鎖桿滑回去鎖定。

    說明書 p.38–39

    記憶卡買哪一種

    GR IV 用的是 microSD / microSDHC / microSDXC,支援 UHS-I 規格 官方規格。要錄影片的話,說明書建議用 Class 6 以上 的卡 p.56。

    GR IV 機身內建約 53GB 記憶體,不插卡也能拍(RAW 約 995 張)官方規格。但還是建議插一張卡,方便讀取與備份 本站建議。

    步驟二:充電

    電池出廠沒充飽,第一次使用前務必充電 說明書 p.172。三種方式:

    • USB 變壓器:接支援 USB Power Delivery 的市售變壓器 + 附贈的 USB 線。
    • 電腦:接電腦的 USB Type-C 埠。要在關機狀態下才會充電,開機會中止充電。
    • 專用充電器 BJ-12(另售)。

    充電時狀態指示燈亮起,燈熄滅就是充飽 說明書 p.40–41。用附贈的 USB 線,充電時間約 2 小時(25°C)p.172。

    一顆電池約 250 張。 這是 CIPA 標準測出的數字 官方規格,說明書自己也寫「要長時間使用,建議攜帶備用電池」p.41。

    步驟三:開機與初始設定

    第一次開機會自動跳出設定流程 說明書 p.42–44:

    1. 按電源按鈕。首次開機會出現 Language 畫面。

    光鏡頭感光元件影像03 / 27

    相機怎麼拍出一張照片

    整本指南最重要的一頁。看懂這裡,後面的設定全都變成常識。

    相機做的事其實只有一件:讓一定份量的光,打在感光元件上。光太少 → 照片太暗;光太多 → 照片死白。

    你只有三個旋鈕可以控制光量

    名稱白話調大會怎樣
    光圈洞多大洞越大越亮,而且背景越模糊
    快門速度門開多久開越久越亮,但會晃、會拖影
    感光度 ISO訊號放多大放越大越亮,但雜訊越多

    這三個合稱曝光三角。它們有一個很關鍵的性質:

    曝光三角的核心

    三個之中,任一個讓照片變亮一倍,另一個就得讓它變暗一半,總亮度才不變。 也就是說,同樣亮度可以用無數種組合拍出來——但每種組合的畫面感覺完全不同。這就是攝影可以創作的原因。攝影通識

    所以模式轉盤在做什麼

    模式轉盤決定的是:這三個旋鈕,哪些你自己轉,哪些交給相機。GR IV 有五種曝光模式 說明書 p.50–51:

    模式官方名稱你決定相機決定
    P程式自動曝光都不用光圈 + 快門
    Av光圈優先自動曝光光圈快門
    Tv快門優先自動曝光快門光圈
    Sn快拍距離優先自動曝光對焦距離 + 景深光圈 + 快門
    M手動曝光全部不管

    另外還有 USER1 / USER2 / USER3 三格,用來存你自己調好的整套設定 說明書 p.127,第 14 章教。

    說明書內文用符號代替這些模式名稱,實際轉盤上的刻印以你手上的機身為準。本站一律用官方全名(程式自動曝光、光圈優先自動曝光⋯⋯)加常見縮寫標示。

    轉盤上哪一顆管哪一項

    不同模式下,前轉盤、後轉盤、曝光補償各自負責的東西不一樣 說明書 p.51:

    模式前電子轉盤後電子轉盤(ADJ)曝光補償
    P 程式自動曝光光圈值快門速度曝光補償
    Av 光圈優先光圈值—曝光補償
    Tv 快門優先—快門速度曝光補償
    Sn 快拍距離優先快拍對焦距離景深曝光補償
    M 手動曝光光圈值快門速度ISO AUTO 時:曝光補償
    ISO 固定時:感光度
    P 模式其實是三個模式

    在 P 模式下轉前轉盤,相機會暫時變成光圈優先;轉後轉盤,會暫時變成快門優先。按一下鎖定按鈕就回復標準設定 說明書 p.52。

    這代表:新手可以一直待在 P,需要時才臨時介入。 本站建議

    AvF5.61/400ISO 40004 / 27

    光圈:洞的大小

    它同時決定兩件事:照片多亮,還有背景多模糊。

    先講數字為什麼是反的

    光圈寫成 F2.8、F5.6、F16 這種格式。最違反直覺的一點是:

    F 值越小 = 洞越大 = 越亮。F 值越大 = 洞越小 = 越暗。
    所以 F2.8 是「大光圈」,F16 是「小光圈」。攝影通識

    GR IV 的鏡頭光圈範圍是 F2.8 ～ F16 官方規格。

    光圈的副作用:景深

    景深就是「照片裡看起來清楚的前後範圍」。

    不用背,相機會告訴你

    GR IV 的拍攝畫面有「對焦欄／景深」這個顯示項目 說明書 p.16(項目 19)。你調整光圈時可以直接看它,比記任何表格都準。

    怎麼調光圈

    1. 按住鎖定按鈕,把模式轉盤轉到 Av(光圈優先自動曝光)。
    2. 轉前電子轉盤,螢幕上的光圈值會改變。
    3. 快門速度由相機自動配合,你不用管。

    說明書 p.50–51

    如果你想留在 P 模式:直接轉前轉盤,相機會暫時切成光圈優先;按鎖定按鈕回復 說明書 p.52。

    光圈的一個硬限制:大太陽下會過曝

    GR IV 的最高快門速度受光圈限制:光圈在 F2.8 時,最快只有 1/2500 秒;要縮到 F5.6 以上,才用得到 1/4000 秒 官方規格說明書 p.163。

    意思是:大晴天想用 F2.8 拍淺景深時,可能快門已經到頂還是太亮。解法是用 ND 濾光鏡。

    ND 濾光鏡:相機內建的墨鏡

    GR IV 內建一片 2 檔(2EV) 的 ND 濾光鏡,可以減光但不改變顏色 官方規格。

    MENU → A2 曝光設定 → ND 濾光鏡 → 自動 / 開啟 / 關閉
    設定意思
    自動相機自己判斷要不要用
    開啟一律使用,拍攝畫面會顯示圖示
    關閉不使用

    說明書 p.91。注意:在手動曝光模式且感光度設為固定值時,「自動」無效;影片模式下沒有「自動」可選 p.91。

    GR IV HDF 版本沒有 ND 濾光鏡,取而代之的是 HDF(高光擴散濾鏡)官方規格。如果你的機身是 HDF 版,這一節不適用。

    還有一個進階選項:程式線

    在 P 模式下,可以告訴相機「你自動配的時候,偏好淺景深還是深景深」:

    MENU → A2 曝光設定 → 程式線 → 標準 / 景深優先(淺) / 景深優先(深)

    說明書 p.53。想在 P 模式也常拿到 F8 左右,可以選「景深優先(深)」本站建議。

    練習 04
    1. 找一個前後有東西的場景(例如桌上排三個杯子),用 Av 模式拍 F2.8、F5.6、F8、F16 各一張。
    2. 回家放大比對:每一張的第二、第三個杯子清楚程度差多少。
    3. 大太陽下試著用 F2.8 拍,看快門會不會頂到 1/2500;然後把 ND 濾光鏡設成「開啟」再拍一次。

    快門:門開多久

    它決定照片多亮,也決定「動的東西」被凍住還是拖成一條。

    數字怎麼讀

    快門速度寫成 1/400 這種分數,單位是秒。1/400 就是四百分之一秒。

    • 分母越大 = 時間越短 = 越暗、越能凍結動作(1/4000 很快)
    • 分母越小 = 時間越長 = 越亮、越容易糊(1/30 就有點慢了)
    • 超過 1 秒的會直接寫成 2"、30"

    GR IV 範圍:1/4000 秒 ～ 30 秒 官方規格。

    手震:新手最常見的失敗原因

    手一定會抖。快門越慢,抖動被記錄得越明顯,照片就整張糊掉。

    安全快門的粗略法則

    手持時,快門速度不要慢於「等效焦距的倒數」。GR IV 是 28mm 等效,所以粗估安全線大約是 1/30 秒。攝影通識

    但這只擋得住「你的手抖」。擋不住「主體自己在動」——路人走路、小孩跑步,你需要更快的快門。

    本站建議:街上有人在動的場合,快門盡量不低於 1/250 秒。(1/125 也能用,但快走的人偶爾會糊。詳細取捨見「別人怎麼設」那一章。)

    ISO 感光度

    光不夠時的最後手段。用得對是救命,用得多是畫質災難。

    它到底在做什麼

    先破除一個誤解

    新手最常見的想法是:「光圈、快門、ISO 是三種讓照片變亮的方法。」

    這句話沒錯,但它漏掉了最重要的一半。正確的說法是:

    核心觀念

    它們是三種不同的付款方式。你要的是亮度,但每一種付款方式扣的東西不一樣。

    你動的換到什麼付出的代價
    光圈開大(F 值變小)變亮景深變淺,清楚的範圍變窄
    快門變慢變亮容易手震、移動的東西會拖影
    ISO拉高變亮雜點變多、細節變少

    所以「該調哪一個」的真正問法是:在這個場景裡,我最付得起哪一種代價? 攝影通識

    決策順序:先問「這張會失敗在哪」

    • 白天還是太亮的話,開 ND 濾光鏡

    快拍 Snap:GR 的靈魂

    不對焦就拍。這是 GR 之所以是 GR 的原因。

    快拍在做什麼

    一般拍照流程是:半按 → 相機找焦點 → 嗶一聲 → 全按 → 拍到。這中間有零點幾秒的延遲,街上的瞬間常常就過了。

    快拍的做法是:你事先告訴相機「就對焦在 2.5 公尺」,按下去立刻拍,完全不等對焦。

    官方定義:「在設定的距離鎖定焦點」說明書 p.58。

    可以設哪些距離

    MENU → A1 對焦設定 → 快拍對焦距離

    八個選項:0.3m / 1m / 1.5m / 2m / 2.5m / 3.5m / 5m / ∞ 官方規格說明書 p.26

    不進選單也能改距離

    按住上鍵(微距)不放,同時旋轉前電子轉盤,就能直接更改快拍對焦距離 說明書 p.58。走在路上隨時可以切。

    為什麼不對焦也會清楚?因為景深

    起手式

    本站建議 Av 模式 + F8 + 快拍對焦距離 2.5m。這組合能覆蓋大部分街頭距離。之後用相機的景深顯示自己微調成你的習慣值。

    完全按下快拍:一台相機,兩種節奏

    你的手指相機的反應

    MENU → A1 對焦設定 → 完全按下快拍 → 開啟

    設為開啟時,拍攝畫面會顯示圖示與拍攝距離 p.64。

    選片與整理

    這章沒有任何相機設定,但它可能是整份指南裡最重要的一章。

    為什麼選片比拍攝更重要

    拍照的技術有天花板,而且不高——曝光正確、對焦準確,大概兩三個月就能穩定做到。

    但是「知道哪張好」沒有天花板。而且它決定了別人怎麼看你的照片:

    如果你把 100 張都貼出來,別人記得的是那 97 張普通的。
    如果你只貼 3 張最好的,別人記得的是你很會拍。
    同樣的照片,不同的選擇,完全不同的結果。本站建議

    三輪淘汰法

    不要一張一張慢慢猶豫,那會花掉一整晚而且選不出來。用三輪快速篩:

    1. 第一輪:技術淘汰(每張 1 秒)
      糊掉的、曝光壞掉的、對焦跑掉的,全部刪。不要留戀,不要想「說不定能救」。這輪通常會砍掉一半。
    2. 第二輪:重複淘汰(每張 3 秒)
      同一個場景你可能連拍了五張。只留最好的那一張,其他刪掉。這輪再砍掉一半。
    3. 第三輪:選出真正喜歡的(慢慢看)
      剩下的裡面,哪幾張你會想給別人看?標記起來。這才是你的作品。

    一次拍攝 100 張,選出 3 張就夠了。 這個比例聽起來很殘忍,但職業攝影師的比例只會更低。攝影通識

    選片時該問自己什麼

    問題為什麼要問
    這張照片在講什麼?如果答不出來,通常就是不夠好
    如果我沒去過那裡,還會覺得好看嗎?分辨「照片好」和「回憶好」
    畫面裡有沒有多餘的東西?好照片通常是減法
    三個月後我還會喜歡嗎?剛拍完都會覺得不錯,放幾天再看更準

    本站建議:拍完當天不要急著選。放兩三天再看,你的判斷會客觀很多。

    每個月選出 10 張,排成一個系列。

    配方三:Sunny 16(理解光線,不是設定)

    晴天 f/16 法則

    出處:傳統攝影法則,收錄於 Wikipedia「Sunny 16 rule」;說明參考 Photography Life、DPReview、SLR Lounge
    難度 ★★★☆☆

    這一組嚴格說不是「設定」,是一個估算光線的能力。學會它,你在任何場合都能猜出正確曝光。

    法則本體:晴天、主體在直射陽光下,把光圈設 f/16,快門速度設成 ISO 值的倒數。

    ISO光圈快門速度
    100f/161/100(或最接近的 1/125)
    200f/161/200(或 1/250)
    400f/161/400(或 1/500)

    Photography Life 提醒:這個法則列出的所有組合並非同樣實用,法則本身也沒這樣主張——例如 f/16、ISO 3200、1/3200 秒在多數情況下不會是你想用的設定。

    怎麼用在 GR IV 上

    GR IV 有測光錶,你不需要真的用 f/16 拍。真正的用法是拿它當基準去校對相機:

    1. 大晴天,設 ISO 100、f/16,看相機給你的快門是不是接近 1/100。
    2. 如果差很多,代表測光被騙了(例如畫面很多白色或很多黑色)——這時該用曝光補償。
    3. 等你熟了,你會在按快門前就知道「這個場景大概該多亮」。

    為什麼值得學:它把「曝光」從一個你看不懂的黑盒子,變成你能預測的東西。這是從新手變成熟手最關鍵的一步。

    爭議一:完全按下快拍該不該開?

    兩位攝影師都把它關掉。 Roman Fox 的理由是他發現自己會不小心觸發它,他寧可清楚知道自己現在是不是在用快拍。

    修正後的建議:先開啟試兩週。如果你發現常常誤觸、拍到不想要的照片,就關掉。

    爭議二:最低快門速度設多少?

    這是三個來源差異最大的一項:1/125(本站原建議)、1/160、1/500。差了兩級以上。

    設定換到什麼付出什麼適合誰
    1/125ISO 比較低,畫質乾淨快走的人偶爾會糊拍靜態、光線好的環境
    1/250大部分街頭都凍得住ISO 略高多數人的甜蜜點
    1/500幾乎不可能糊ISO 會衝很高拍快速動作、不在意雜點

    修正後的建議:改用三檔思考,而不是死記一個數字——

    • 保守 1/125:光線充足、主體靜態,要最好畫質
    • 通用 1/250:一般街拍,建議從這裡開始
    • 積極 1/500:人很多、動作快,寧可犧牲畫質也不要糊

    指南前面章節寫的 1/125 是偏保守的起始值。你可以直接從 1/250 開始。

    走近。這是唯一解,沒有第二個辦法。事後裁切會損失畫素。
    選單路徑
    用腳,不用選單。
    想懂為什麼

    畫面很亂 = 元素太多,沒有主角

    診斷
    28mm 視野很大,很容易把不想要的東西一起拍進來。
    立刻做
    減少畫面中的元素;換個角度讓背景單純(蹲低拍天空、找一面素牆);再靠近一點。按快門前掃一次畫面四角。
    選單路徑
    打開格線當構圖輔助:MENU → D3 顯示自定義 → 拍攝資訊顯示設定 → 格線
    想懂為什麼

    照片老是歪的

    診斷
    手持時很難靠感覺抓水平,尤其畫面裡沒有明顯的水平線時。
    立刻做
    打開電子水平儀 說明書 p.139;再開自動水平補正,相機會自動修(SR 開啟時最大 1.0 度,SR 關閉時最大 1.5 度)p.96。
    選單路徑
    MENU → A6 拍攝輔助 → 自動水平補正 → 開啟
    想懂為什麼

    人臉被拉長 = 廣角邊緣變形

    診斷
    廣角鏡頭在畫面邊緣一定會有拉伸,越靠角落越明顯。這是光學特性。攝影通識
    立刻做
    把人往畫面中間放。這是構圖問題,沒有選單可以修。
    選單路徑
    重新構圖,不用選單。
    想懂為什麼

    白天街拍:起手設定

    立刻做
    曝光模式 Av 光圈優先 / 光圈 F8 / 對焦快拍 2.5m / 完全按下快拍開啟 / ISO AUTO 上限 6400 / 最低快門速度 1/250 / 測光多區 / 影像控制正片。
    為什麼
    F8 的景深夠深,配上快拍就是「舉起來就拍到」,零對焦延遲。1/250 讓走動的路人不會糊。
    出處
    本站建議 這是起始值,不是官方規定。選項名稱與位置依官方說明書。
    完整版

    夜間 / 低光:起手設定

    立刻做
    光圈 F2.8 / 對焦選擇 AF(暗處快拍容易失手)/ ISO AUTO 上限 12800～25600 / 最低快門速度 1/60 / 測光高亮重點 / 曝光補償 −0.7 ～ −1.3EV / Shake Reduction 開啟。
    為什麼
    高亮重點讓霓虹燈不會白掉;負補償保住夜的氣氛。找牆壁、欄杆、地面靠著拍,比任何防手震都有效。
    出處
    本站建議 起始值。測光方式依 說明書 p.65。
    完整版

    室內 / 陰天:起手設定

    立刻做
    光圈 F2.8 ～ F4 / ISO AUTO 上限 6400 / 最低快門速度 靜物 1/60、有人在動 1/250 / 白平衡自動白平衡(暖色優先) / 測光多區。
    為什麼
    暖色優先會保留室內燈光的暖調,不會把氣氛校正掉 說明書 p.73。
    出處
    本站建議 起始值。
    完整版

    微距 / 食物與小東西:起手設定

    立刻做
    微距模式開啟(按上鍵,對焦 6～15cm)/ 光圈 F5.6 ～ F8 / 對焦精確 AF / Shake Reduction 開啟。
    為什麼
    這麼近時景深極淺,要縮光圈換深度。近距離也會放大手震。
    注意
    微距模式下無法使用完全按下快拍 說明書 p.64。
    完整版

    長曝光(車軌、流水):起手設定

    白天太亮時
    開啟 ND 濾光鏡 說明書 p.91,否則長曝一定過曝。

    B. 從想要的感覺挑濾鏡

    GR IV 的「影像控制」就是機內濾鏡,選好之後拍出來的 JPEG 直接是那個味道,不用後製 說明書 p.92。下面不從 14 個名字裡挑,而是從你想要的感覺反查。

    你想要什麼感覺

    真實乾淨 → 標準

    官方說明
    標準畫質 說明書 p.92
    建議參數
    不動。這是基準點,先用它拍一陣子,你才知道其他色調到底改了什麼。本站建議
    適合
    要記錄、要後製、或不確定的時候。
    選單路徑
    MENU → A5 影像加工設定 → 影像控制 → 標準

    濃郁鮮豔 → 正片(或鮮艷)

    官方說明
    正片:拍攝如使用正片拍攝的高飽和度影像。鮮艷:拍攝清晰醒目、色調鮮明的影像 說明書 p.92
    建議參數
    先用正片不動參數。想再重一點,按 Fn 進去把對比度 +1。本站建議
    適合
    晴天、藍天、風景、招牌顏色多的街景。這是 GR 的招牌色。
    選單路徑
    MENU → A5 影像加工設定 → 影像控制 → 正片

    日系淡雅 → 底片

    官方說明
    拍攝如使用底片拍攝的影像 說明書 p.92
    建議參數
    按 Fn 進去把飽和度 −1、對比度 −1,想要顆粒感再把粒紋感 +1。本站建議
    適合
    陰天、室內、生活隨拍。光線很硬的大晴天用這個會顯得灰。
    選單路徑
    MENU → A5 影像加工設定 → 影像控制 → 底片

    黑白硬派 → 高對比度黑白

    官方說明
    拍攝突出對比度的黑白影像。拍攝具有粗糙感的影像,如在膠片照相機中使用超感光度膠片 說明書 p.92
    建議參數
    按 Fn 進去把粒紋感 +2。黑白專用的濾光鏡效果可以讓天空變深,值得試。本站建議
    適合
    街拍、強烈光影、陰影很重的場景。這是 GR 最有名的黑白。
    選單路徑
    MENU → A5 影像加工設定 → 影像控制 → 高對比度黑白

    黑白柔和 → 軟單色

    官方說明
    拍攝給人柔和印象的黑白影像(影片模式無法選)說明書 p.92
    建議參數
    不動。想更硬一點就改用硬單色(給人硬朗印象),想最中性就用單色。本站建議
    適合
    人像、靜物、光線柔和的室內。
    選單路徑
    MENU → A5 影像加工設定 → 影像控制 → 軟單色

    電影感 → 電影(黃色) / 電影(綠色)

    官方說明
    電影(黃色):拍攝帶黃色調的電影感影像。電影(綠色):拍攝陰影側帶綠色調的電影感影像 說明書 p.92
    建議參數
    兩個都拍一張再決定——黃色版偏暖偏懷舊,綠色版偏冷偏疏離,差異在陰影裡最明顯。本站建議
    適合
    夜晚街景、有燈光的室內、想要敘事感的畫面。
    選單路徑
    MENU → A5 影像加工設定 → 影像控制 → 電影(黃色)

    舊照片 → 懷舊

    官方說明
    拍攝仿若舊照片的影像 說明書 p.92
    建議參數
    不動就很到位。想更舊可以加粒紋感。本站建議
    適合
    老街、舊建築、家庭紀錄。
    選單路徑
    MENU → A5 影像加工設定 → 影像控制 → 懷舊

    想玩點怪的 → 正負逆沖 / 跳漂白

    官方說明
    正負逆沖:更改色彩及對比度,拍攝如進行了交叉沖印的影像。跳漂白:拍攝降低飽和度、突出對比度的影像 說明書 p.92
    建議參數
    這兩個個性很強,不建議當日常設定。挑特定場景玩就好。本站建議
    適合
    跳漂白適合冷硬的都市場景;正負逆沖適合想要不真實感的實驗。
    選單路徑
    MENU → A5 影像加工設定 → 影像控制 → 跳漂白

    選單路徑
    MENU → A5 影像加工設定 → 影像控制 → HDR 色調
